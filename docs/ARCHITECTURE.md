# MeGit 架构

## Windows 桌面外壳

`desktop/` 独立打包 Tauri、内置 Node.js 和网页版生产文件。双击启动时获取单实例锁，由外壳启动后端并通过专用输出管道等待实际监听成功，然后让 WebView2 从 `http://127.0.0.1:43217` 加载界面与 API。端口冲突时不接管已有服务；原有 Host、同源、会话令牌和登记路径检查保持不变。只有 `main` WebView 的固定回环来源可调用窗口设置与控件命令，不授予文件、Shell 或其他通用 Tauri 权限；外站 HTTP(S) 链接交给默认浏览器。退出关闭控制管道，后端关闭原有受管服务；外壳异常退出也会断开控制管道。浏览器版入口不依赖桌面工具链。

桌面数据在 `%LOCALAPPDATA%/app.megit.desktop/data/`，与安装文件、浏览器版 `.megit/` 和 WebView2 偏好分离。桌面版的仓库 npm 脚本只用系统 PATH 上配套的 Node/npm，不用随应用分发的 Node；PowerShell 与 Git 保留原行为。[桌面版使用与构建](../desktop/README.zh-CN.md)。

系统标题栏、关闭到托盘保存在同一应用本地目录的 `window-settings.json`，不写入白板或浏览器偏好。系统关闭请求与应用内关闭共用拦截；只有关闭到托盘开启且隐藏成功才保留进程。托盘的「退出 MeGit」直接走退出清理路径，不再次触发隐藏；再次启动唤醒已有窗口。

## 本地服务

白板底栏通过现有会话校验下的只读 `GET /api/local-services` 汇总已登记工作树中受管服务的活动状态，不返回配置、日志或路径；详情仍走原仓库接口。列表包含其他白板中登记的受管服务，不启动或停止项目。

白板卡片通过 `GET /api/local-services?boardId=…` 一次读取当前白板的 HEAD 仓库服务摘要，仅返回仓库标识、已保存配置的修订号、运行状态、运行中的起点和必要错误。运行起点由后端在服务就绪时记录于内存，前端用该时间每秒计算已运行时长；刷新页面不影响计时。未配置的仓库不返回摘要；分支引用卡片不显示快捷控件。同一画布的动作请求在仓库级防止重复，并复用原服务路由与校验；卡片控件不进入白板数据、撤销历史或导出。

仓库详情的「本地服务」按登记工作树的规范路径读写本机数据目录 `local-services/`，与白板、分支卡片和浏览器偏好分离，只有显式保存才授权、只有用户操作才启动。API 复用 Host／同源／会话令牌边界；写请求带配置修订号，执行请求只接受动作与修订号。服务端复核目录、真实路径、工作树边界、当前分支和 HEAD，以及指定入口文件的内容指纹。指纹不是对全部仓库代码和依赖的审计，脚本仍以用户权限运行。每个工作树只有一个受管服务。

Windows 后端用固定的 PowerShell 监督程序将前台进程和后代纳入独立 Job Object，停止只关闭该组。MeGit 退出时控制通道关闭，监督程序清理进程；Windows 在 Job 句柄关闭时兜底。IPv4/IPv6 的 TCP 监听只用于检查冲突与核验就绪，遇到外部监听显示占用 PID，不终止或接管它。未填端口时只判断进程组存活。近期输出在内存中限制为 16,000 个字符，错误用稳定代码呈现；不会写白板，也不会发给 AI。

## 仓库卡片引用

白板的流程图可见性与小地图、缩放锁和画布工具一样，按白板在当前标签页内记忆，刷新不写入工作区。仓库索引活动／归档分类也随标签页恢复，编辑和确认表单不恢复。

仓库节点可选保存独立的 `displayName`，不写回仓库索引。白板、仓库详情、关系两端和分组成员均显示对应节点的名称。未设置时使用登记名称；从白板首次登记的仓库以文件夹名称作为默认名称。旧白板无需迁移。

版本 1 的仓库节点可选保存完整本地或远端跟踪引用；未绑定的卡片沿用 HEAD。仓库登记仍按路径唯一，白板允许同一个仓库的不同引用，详情按卡片标识独立打开。关系省略显式引用时从端点继承，快照和整合历史共用解析规则。分支地图和指定分支历史使用只读引用；工作区操作按实际检出分支显示，绑定卡片的写操作还在服务端 Git 队列内复核分支。

## 网络代理

`network-settings.json` 与白板、浏览器偏好和 AI 密钥分开保存。代理仅在请求启动时应用：Git/GCM 通过子进程参数和环境获取，AI 走请求级代理，不修改进程全局状态或 Git 配置。本机路径和回环地址直连；开启后不支持的远端协议被明确拒绝，失败不自动直连。代理测试是独立的 GitHub 连通性请求，不修改配置。

## 内置 AI 助手

连线「AI 审阅」复用 `/api/ai/assist` 的现有模型配置、凭据和代理。请求仅提交关系选择、明确同意和审阅指纹；后端按原登记路径和连线校验读取快照，不接收客户端提供的差异或任意文件路径。合并前仅发送面板内有界提交摘要与来源差异；准备后仅发送暂存差异、冲突路径和就绪状态。模型收到的是不可执行的数据及纯文本任务，无工具；请求前后比对指纹，丢弃过期建议，结果仅保存在面板内存。

聊天输入框左下显示当前对话的能力范围。默认范围保持原有仓库上下文和工作流交互；「仓库读写」须先启用 AI 项目交付总开关，仅对聊天中唯一引用的仓库显式授权。服务端以不持久化的随机授权 ID 绑定对话、单个登记工作树与 AI 设置修订，发送时复核仓库引用与授权一致。更改仓库引用、撤权或更改 AI 设置会使相关文件方案失效。后端复核真实工作树、分支与 HEAD。授权请求不联系 AI 服务；发送消息后，现有聊天上下文附加过滤后的相对文件名，之后接受最多三轮结构化读请求（共 12 个文件／48 KiB）。只读取普通 UTF-8 小文件，不接受符号链接、硬链接、嵌套工作树、隐藏或忽略路径与常见敏感文件。直接读取的文件内容和文件方案不写入持久聊天历史。模型没有终端、网络抓取或任意 API 工具；同一回复可返回普通答复、原工作流方案或文件方案，不混合确认。

交付计划最多修改或新建 6 个文本文件，不创建目录、删除文件或执行 Git。后端保存 15 分钟有效的单次计划；应用要求计划 ID、原对话的有效授权及选项，在写入前逐一复核读取文件与写入目标。文件保存先于可选的本地服务配置；配置要求显式信任，使用原保存逻辑验证配置修订和刚审阅的入口内容指纹，不会启动。批量操作不跨文件回滚；如果中途失败，显示实际已写文件和错误。

`shared/assistant-guidance.ts` 将回复快捷入口限制为登记仓库 ID 与七种导航类型。模型可返回 `guides`，旧格式回复从实际仓库状态补齐；服务端按所选范围、可用性去重过滤。`GET /api/ai/assistant/repositories/:id` 经同一令牌／同源／登记路径校验读取最新状态。前端仅在最新回复显示按仓库分组入口，15 秒更新并在点击前重新读取；失效按钮收起。远端动作复用 `RemoteActionButton`／`RemoteActionDialog` 与原仓库操作锁，工作区／分支地图复用已有组件，确认及 Git 队列校验保持不变。引导随消息保存；确认表单不恢复，也不构成执行授权。错误通过稳定代码映射到设置、刷新及重新准备入口。

`shared/assistant.ts` 定义多仓库会话与有限操作协议；`server/assistant.ts` 按已登记且用户选定的仓库投影上下文，模型只返回解释和fetch／stageAll／commit／push建议，不接受路径、任意Git参数或终端命令。`aiRouter`复用配置解密和请求级代理，Chat Completions支持多轮assistant角色；用户显式选择后才发送暂存差异，合计48k字符。历史中的计划编号只用于服务端提取所选仓库的实际执行结果，不能当作执行授权。

计划仅在本地服务内存保存，最多100份、15分钟有效，以不可预测ID引用。执行请求原子应用本次审阅提交说明并将ready转为running，不接受客户端替换操作列表；一次计划只能开始一次。登记路径再次解析，既有Git队列内guard在每步前后校验状态、文件流式摘要（每仓库2000文件／128MiB上限）、配置摘要及index；提交核对父提交、说明和已审阅暂存对象，暂存前按Git clean过滤规则计算预期blob，暂存后逐路径核对实际对象并保持范围以外index不变，不依赖可被assume-unchanged遮蔽的状态。远端／跟踪变化不吸收为新基线。继续使用原远端快进、预期远端引用与代理校验。外部钩子导致变化会报告失败并保留已发生的操作；不提供跨仓库回滚。

`AssistantPanel`迁移MeWiki聊天视觉结构，改用MeGit本地组件、品牌和双主题token。面板独立浮动，不替换Git检查器；`AssistantPlan`展示真实计划与本地设计规范实例。`assistant-session.ts`严格校验有界会话、引用、草稿与审阅消息，浏览状态保存在当前标签页；不保存可自动重放的操作。刷新只GET查询服务计划，服务重启后显示失效。发送可取消，执行使用独立服务状态及停止标志，关闭面板不假称当前Git操作已取消。

`AssistantLauncher`提供屏幕边缘入口、拖动吸附与比例位置记忆，替代导航助手按钮。`assistant-layout.ts`集中计算无保护间距的窗口限幅和八向缩放，相对边不漂移；窗口框架与悬浮球分别保存浏览状态。规范页使用真实组件的preview模式和独立示例会话，不加载服务配置或计划。

AI 路由复用现有本机、同源和会话令牌校验。`server/ai.ts` 内部分离服务配置、传输和任务分发；第一版使用单一 Chat Completions 兼容配置。密钥由 Windows 当前用户 DPAPI 保护，`ai-settings.json` 独立于白板和浏览器偏好，配置 API 只返回密钥是否存在；请求不跟随重定向，不透传服务商错误正文。

旧版仓库解读经注册仓库检查后只投影状态数值和布尔值；软件设置的流程草稿入口只发送用户输入，不隐式附加白板。模型结果是文本或经过共享契约校验的草稿，不是指令。仅用户点击确认后，经既有白板历史和保存流程加入节点与连线。

聊天助手通过可选 `boardId` 显式引用当前流程图，旧会话与新会话默认关闭流程引用，流程快捷问题会主动加入引用。`shared/assistant-board.ts` 定义严格有界的步骤、流程线、位置、布局和流程元数据操作及共享纯应用器；服务端仅读选定白板（不附加仓库登记路径），上下文超过200,000字符直接拒绝，不静默截断。模型产生操作后整批模拟校验，重新读取白板核对内容签名，返回15分钟有效的审阅计划；不接受混合 Git 写计划、不执行步骤文本、不删除仓库卡或修改登记／绑定／Git 关系语义。拓扑分层排布保持并行分支，环按稳定顺序拆层，仓库组作为整体保持内部布局。

`AssistantBoardPlan` 展示完整修改字段和真实位置图形预览（含组框、仓库和已有关系）。确认时再次校验白板ID、内容签名、有效期、保存状态与布局锁；`App` 用一次 `useWorkspace.update` 应用整批纯函数结果，共用既有撤销、串行自动保存及版本冲突反馈。视口移动不使计划失效，内容改变则失效。会话仅保存操作、签名与已应用／放弃标记，不保存整板快照，刷新不重放；保存失败保留本地内容并使用既有持久错误提示。

仓库卡片提交说明任务显式发送登记仓库的暂存差异，`server/ai-commit.ts` 使用禁止外部 diff／textconv 的只读命令，有界读取并截断到 48,000 字符，不含二进制原始数据。读取前后及模型返回后复核 HEAD、分支与暂存对象指纹，拒绝过期结果；模型输出只接收最多 240 字符的单行文本。`useRepositoryActions` 共用仓库忙碌锁和提交草稿，按最新草稿比较后写入，卸载／切换对象中止请求；客户端断连传递取消信号至上游，仍保留 45 秒超时。结果不触发 Git 写操作，错误使用稳定双语代码，密钥和根路径不附加到提示。

## 可连接维护流程

版本 1 数据向后兼容增加 `FlowNote.kind`（note／process／decision／start／end）、`summary` 与 `Board.connections`。流程线独立于 Git `edges`，端点仅接受真实仓库节点与说明／步骤，不能指向分组或悬空对象；标识和重复连接由服务校验，删除任一端点原子清理相关流程线。Git 快照、比较及写操作仍只处理原有仓库关系。

`FlowStep` 共用实际步骤图形，`ProcessEdge` 绘制带箭头和条件标签的流程线；默认正交路由，可选世界坐标折点用于外侧失败回路，选中流程线后通过 React Flow 端点拖拽重新连接真实节点或端口，保留 id／条件并清理旧折点，一次成功操作产生一次历史；无效、重复、自连接或空白释放不修改原线。来源重连反向启用 source 端口落点。Git 关系不启用重连，折叠组投影需先展开，布局锁定和平移模式禁用。条件编辑器只编辑文字及按需恢复自动路由，不设置端点。流程形状及导出均无填充，详情由 Enter 或选中工具栏打开。折叠仓库时将外部流程线投影到分组动态端口，不修改真实端点；焦点上下游同时包含两类线。`BoardHistory`、吸附、排列及导出保留步骤、形状与流程线，导出只含可见摘要，不自动包含命令等详情。

## 分层

```text
src/                 React 页面、流程白板、详情与交互
  components/        React Flow 节点／连线、仓库面板、关系表单与差异查看
  lib/api.ts         独立的 HTTP transport
  lib/use-workspace  本地编辑与串行自动保存
  i18n/              i18next 实例、类型化本地语言资源与语言注册
  preferences/       版本化浏览器偏好、订阅与首屏外观应用
  themes.css         dark / light 语义颜色契约
  tokens.css         两主题共用的尺寸、间距、排版与圆角
shared/types.ts      仓库、流程、关系、Git 状态的共享投影
shared/messages.ts   稳定的应用错误代码与消息协议
server/app.ts        同源本机 API、输入校验、登记路径访问
server/git.ts        execFile 调用系统 Git、解析结构化输出
server/branch-tree.ts 只读分支引用、上游／worktree 映射、有界历史和固定 SHA 比较
server/workspace.ts  校验、版本冲突检查、串行原子保存
server/index.ts      127.0.0.1 入口，开发 Vite 中间件／正式静态资源
```

Git 核心不依赖 Express 或 React。前端通过 transport 访问服务，未来可将 HTTP transport 替换为桌面 IPC，或使用桌面外壳启动现有本机 sidecar；首版未加入 Electron、Tauri 或打包运行时。

仓库详情默认使用 `BranchTreePanel` 加载分支树，`BranchTree` 和 `src/lib/branch-tree.ts` 分离图形渲染与纯布局，复用于设计规范页。工作区和历史由按需模态承接；提交草稿与忙碌状态仍归各仓库根组件所有。更换树干不执行 checkout。分支树路由只接受登记仓库及现有完整引用／HEAD，使用真实父 SHA、独立上游计数与 worktree 路径。默认 120 条、上限 600，遗漏枝梢保留真实父信息并显示边界。比较在固定 SHA 上核对完整独有计数，返回有限 SHA 集合供图形强调；引用过期返回稳定错误，异步旧响应不覆盖新选择。当前分支同步同时核对快照与图中的分支／HEAD，刷新期间禁用。压缩至少保留每条真实开发线的锚点，分支名称删除后仍可辨认其分叉和合流。

添加远端、获取、发布、设置跟踪、拉取和推送使用独立操作。发布与设置跟踪在仓库写队列内复核确认时的分支和 HEAD；发布要求目标不存在，推送要求远端引用仍等于本机记录且更新可以快进。写入时再次由 Git 检查预期远端引用，防止并发覆盖或重建已删除的上游。单次发布或推送不支持多推送地址，不推送标签或子模块。

远端管理只查看登记仓库所选远端的本机配置。读取检查显式调用非交互 `ls-remote`，不写入远端引用或 `FETCH_HEAD`，也不推断账号或写权限。仅对 Git 实际解析为 GitHub.com HTTPS 的读取地址提供浏览器登录；服务端在启动 Git Credential Manager 前重新核对地址，不接收、保存或返回凭据，登录不触发读取检查或同步。

分支连线沿独立竖直轨道绘制，跨轨道只在提交端点附近使用平滑弯道：按横向跨度调整到 48–88px，并限制在父子纵向间距的一半内；每个弯道只用一个中间锚点，进入直线和经过中间锚点时保持切线与曲率连续，不再将整段历史绘成贴近树干的长曲线。首父连接优先保留轨道；合流遇到继续开发的源分支或已有重叠线段时使用相邻空轨道，避免穿过无关提交。额外轨道需要空间时对称扩展画布，树干继续居中。此路由仅改变几何，不改变父关系、折叠、引用或比较语义。

## 主题与国际化

浏览状态由 `src/lib/view-storage.ts` 和 `use-view-state.ts` 管理，版本 1 存于当前标签页的 `sessionStorage` 键 `megit.view-state`，与跨标签页同步的偏好及服务端工作区分离。按白板 ID、仓库 ID 和路径分隔详情、分支视角、地图／详情滚动、只读查看窗口及提交说明草稿。当前查看的工作流在初次读取时仅恢复到仍存在的白板，独立于工作区自动保存的等待时间，不主动发出保存请求。刷新时校验格式、尺寸、对象和引用，失效对象清理；损坏或存储不可用时显示双语提示并保留内存操作。仅淘汰未订阅旧记录，保护打开组件；记录和容量有界。

`useScrollMemory` 在异步内容准备后恢复真实滚动容器，默认居中与详情定位避让已保存位置；窗口缩小时重新限幅拖动偏移。Git 课堂保存课程、步骤及真实内部滚动，恢复后暂停。Dialog 和共享组件通过可选 `viewKey` 接入，设计规范示例不接入产品会话。仅允许恢复的浏览弹窗进入持久记录，Git 写操作、确认表单、临时菜单与 tooltip 不保存或重放。

分支地图右上角的单一工具区由 `BranchTree.tools` 插槽承接业务入口，真实空态与错误仍保留工具，首次读取完成前仅显示加载状态，避免菜单在数据返回后重新挂载关闭；`BranchTrunkDialog` 按需选择并确认比较视角，复用于设计规范页，不执行 checkout。图形视口保留原生普通滚轮滚动，使用非被动原生 wheel 监听接管 Ctrl+wheel／双指捏合缩放；Shift+wheel 仅横向滚动，鼠标右键通过指针捕获平移并在松键、取消、失焦时结束。缩放范围 0.5–2，以鼠标位置和居中留白计算锚点。缩放比例与待提交滚动位置一起更新，连续反向事件回到原比例也提交位置；仅首次显示非空地图时在绘制前定位树干；点选标签、连线、提交、关闭浮层、筛选选择及后续数据更新不自动居中或滚动。主动居中按钮、缩放锚点和用户滚动／拖动继续改变视角。普通水平滚动保持原生行为，详情与工具位于视口之外。直接点选详情在布局提交时安静聚焦，不延迟抢回用户已移动的焦点；搜索选择在原生 Dialog 关闭并恢复入口后再交接焦点，重复选择仍可用 Escape 收起详情。工具菜单按地图实际高度限幅并内部滚动。

组件共用语义 CSS token，`data-theme` 决定暗黑或明亮，首屏默认暗黑。i18next／react-i18next 提供类型化语义键、本地资源、插值与复数，Intl 负责时间。偏好以独立版本协议存于浏览器 `megit.preferences`，使用订阅机制驱动即时切换与同源多页同步，不写进流程数据。首屏引导在应用加载前同步设置主题，避免闪白。

`Tooltip` 与 `PopupMenu` 统一管理临时提示和动作面板；`src/lib/overlays.ts` 协调浮层互斥与自动焦点移动。对话框、菜单和窄屏导航复用安静的焦点恢复，保留键盘可访问性并避免恢复焦点重新弹出提示。外部事件在捕获阶段识别，不受画布停止冒泡影响。

所有 `Tooltip` 使用原生 manual Popover 进入浏览器 top layer，以固定屏幕坐标定位，空间不足时换向，并与视口边缘保持 8px；不依赖祖先 z-index 或可选 portal。提示节点仍属于原触发器 DOM，保留原生模态内的可访问性和主题继承。滚动、窗口变化与既有关闭事件统一收起提示。

`InfoPopover` 以同样的原生顶层浮层按需展示仓库资料，沿用浮层互斥、外点／焦点离开关闭与安静焦点恢复。`RepositoryInfo` 只读取现有仓库和快照数据，将路径、完整 HEAD、跟踪、远端名称和时间收起，不增加 API。`GitHelp` 从本地双语资源提供标题、含义及结果，`HelpTip` 统一悬停、键盘与点击固定；详细 tooltip 支持移入阅读和内部滚动。必要状态与未知比较原因独立于帮助和可折叠依据展示。

API 以稳定错误代码和脱敏技术详情返回应用错误；客户端保留结构化错误并按当前语言解释。仓库不可用、整合状态说明和非文本差异使用结构化状态。Git 原始输出及用户内容保持原样。主题与语言的新增流程、例外和验收见 [THEME_I18N](THEME_I18N.md)。

折叠导航使用 `NavigationFlyout` 在图标右侧按需展示工作流和当前白板仓库列表，复用 `WorkspaceNavigation` 的相同列表渲染及动作。浮层使用原生 manual Popover、顶层定位和浮层互斥协议，保留安静焦点恢复；外点、焦点离开、外部滚动、窗口变化和 Escape 收起，长内容内部滚动。展开导航或进入窄屏时卸载临时浮层，不改变导航折叠偏好。`NavigationExample` 在设计规范页提供同一组件的本地数据示例。

## Git 图解课堂

`CollapsedCommitsPopover` 只读取当前 `BranchTreeData` 中折叠边的 `child → via → parent`，由纯函数 `commitSegment` 校验相邻真实父关系、缺失和重复编号后显示局部链，不请求新接口或重排全图。两端上下文仅用于校验父关系，显示为延伸线，不创建端点标记或点击目标；默认只显示图形，选中提交复用 `CommitPointActions`、既有差异回调和固定 SHA 新建分支表单。`dismissPopups` 可显式保留父浮层，子菜单打开只保留自己的局部树，其余浮层仍互斥；关闭子菜单安静返回提交点，Escape 逐层收起。浮层沿用 top layer 和安静焦点约定，不写偏好、白板或浏览状态。

`src/lib/git-learning.ts` 定义七组不可变虚构场景，包含文件版本、提交父节点、分支／HEAD、远端跟踪引用及冲突阶段，不依赖 transport、工作区或 Git。普通合并组合不同文件的独立修改；冲突课单独演示同一位置修改、编辑、暂存和合并提交，不能用动画跳过真实语义。

`GitLearningDialog` 从帮助标题动作打开，`GitLearningScene` 使用本地 SVG、文件卡片与语义 token 展示变化；播放器仅推进内存帧，不发起 API 请求。切课、手动跳转、失焦和页面隐藏暂停播放。共用 `Dialog` 的 `headerActions`、`draggable`、`persistent` 为可选功能，默认关闭规则保持原样；课堂必须显式关闭，保留原生模态焦点约束。`use-dialog-drag` 基于已渲染偏移计算视口限幅，捕获指针且支持取消、键盘移动和窗口缩放，防止同批次事件突破边界。学习进度和窗口位置仅属于当前打开会话。

`src/lib/git-learning-media.ts` 将 14 类语义操作映射到课堂原步骤，`GitLearningPreview` 复用同一图形渲染器的紧凑展示；不复制场景或绑定真实仓库。`Button`／`IconButton` 可选 `learningDemo` 经 `GitDemoTooltip` 显示单个高级提示，默认行为保持原样。动画按需挂载、有限播放、关闭清理，静态／减少动态直接展示结果；`active` 支持常驻隐藏容器停止播放。共用 Tooltip 支持可选悬停延迟和尺寸观察，取消等待不迟到弹出，过滤焦点自动滚动的迟到通知。接入方法与语义边界见 [Git 功能演示接口](GIT_LEARNING_MEDIA.md)。

## 工作流数据

产品界面中一个工作流对应一张画布。「工作流」指可创建、保存、切换、导出或移除的对象；「画布」指摆放与浏览节点的区域。现有 `Board`、`boards`、工作区 API 和持久化字段保持兼容，不需要迁移旧工作区。

`edge-route.ts` 提供自动路线转角提取、线段法向移动、圆角路径和写回校验。`useEdgeRoute` 为仓库关系和流程线提供共用编辑器，通过左上副工具栏启用；短柄平移线段，圆点修改折点，首尾线段编辑保留真实端点。拖动预览仅本地状态，指针释放一次写回并进入现有历史；取消、第二触点、失焦、缩放或来源变更结束手势且不保存，控制点命中尺寸不随缩放改变。`FlowEdge.waypoints` 与既有流程线协议一致，最多 20 个有限坐标，服务校验并持久化；修改关系文字保留路线，更换真实端点清理路线。选中路径的控制点与标签分开显示，布局锁定、平移模式和折叠投影不允许编辑。导出复用实际 SVG 路径，规范页使用同一编辑器及本地演示状态。

`edge-route-snapping.ts` 为共用路线编辑器计算横竖吸附：折点参考相邻点，水平／垂直线段仅沿法向参考本路线固定点，斜线段不强行改变方向；真实端点固定。复用 SnapLocks／SnapGuide、6px 进入与 10px 释放，稳定候选和缩放换算。useEdgeRoute 订阅既有 snappingEnabled，Alt 按下／松开在原位置重算预览；参考线仅瞬态渲染，结束和取消清理，不进入工作区、历史或导出，键盘微调不受吸附影响。

`RepositoryPorts` 订阅 React Flow 当前可见连接，逐边判断真实的输入／输出使用情况：仅单一方向或空闲时合并在 50%，两种方向同时存在时在 43%／57% 对称分离。保留既有 source／target handle ID 与端口持久协议；共享点根据当前拖动或点选连接的方向切换命中入口，支持从仅入线的点继续发起出线。布局变化重测节点，兼容撤销、过滤投影和折叠后展开；不增加工作区字段，导出继续读取实际路径。`RepositoryPortsExample` 在设计规范页复用真实组件展示四种方向状态。

Workspace 包含全局仓库索引和多个 Board。每个 Board 独立保存节点位置、视角和有向关系；节点引用 Repository，关系引用节点。相同仓库可进入多个流程；流程关系目前是描述和比较，不是自动运行的流水线。

Board 可选 `groups` 保存平面分组的 id、名称、成员节点和折叠状态。成员互斥、不能为空，分组 id 不与节点 id 冲突；服务端同时校验成员引用与唯一性。节点始终保存绝对坐标，分组边界根据实际节点尺寸计算；整体移动以同一位移原子更新所有成员，达到坐标边界时共同限幅。折叠只在 React Flow 投影中隐藏成员和内部边，外部边映射到带独立连接点的组外壳，真实边 id、仓库端点、引用与比较结果不变。解散不移动仓库，移除节点时同时清理空组及悬空边。

FlowEdge 可选 `routing`（smoothstep / step / bezier / straight）、`sourcePort` 与 `targetPort`（top / right / bottom / left）。旧数据缺少这些字段时仍有效；自动路线按卡片中心选择相对连接边，已有手动折点沿用右出左入。显式端口始终优先。`relation-ports.ts` 仅计算显示投影，折叠组与拖动预览使用相同端口；端口不参与 Git 状态判断。`RepositoryRelationEdge` 复用路线编辑器绘制状态桥，独立 SVG marker 适应末端切线，标签及帮助复用 Tooltip；`ProcessEdge` 继续表示带箭头的执行顺序。`src/lib/whiteboard.ts` 集中分组投影、移动、成员维护与可达上下游计算，React Flow 继续接收节点实际尺寸与受控位置。

持久化使用版本 1 的 `.megit/workspace.json`；写入需要当前 revision，在进程内串行校验并以临时文件 rename 替换。客户端合并编辑并顺序提交，写入期间出现的新修改会接着保存。视角更新使用专用入口进入同一队列，仅保存视角时连线快捷操作保持可用。存在待保存的其他编辑或保存失败时，连线快捷操作继续受保存状态约束。连接／传输失败保留页面内修改并停止队列，人工重试继续原队列；发生版本冲突后停止写入，不提供重试覆盖，提示刷新，避免覆盖其他页面修改。

`src/main.tsx` 按路径选择主应用或 `/design-system` 真实组件示例。示例复用基础按钮、字段、面板头和偏好设置，使用局部演示状态，不挂载 `App` 或 `useWorkspace`，不发起 API 请求。共用组件和白板交互规则见[产品设计规范](DESIGN_SYSTEM.md)。导航和检查器尺寸变化不主动适应白板，保留当前视角；初次显示、新增对象、主动聚焦和适应白板入口继续定位内容。

`WorkflowHeader` 在主工作区顶部横跨画布和右侧详情，使用现有 Board 数据绘制标签。`app.workflow-tabs` 保存当前页面打开的顺序，`app.board` 保存活动工作流，兼容旧的单工作流关闭记录。`useWorkspace.selectBoard` 更新内存投影与该板撤销状态，不启动保存；切换时沿用各板已保存视角。关闭最后一个标签保留右侧详情与重新打开入口。左栏标题行的独立显隐按钮用 `app.workflow-hidden` 记住画布显隐，不关闭标签，也不改写白板。系统标题栏隐藏时，窗口控件在同一栏右侧，独立于标签滚动区域。

`src/lib/inspector-dock.ts` 管理工作流内打开的仓库与关系 Git 详情，以类型和对象 ID 去重，与画布选择分离。打开项、活动项和宽度按工作流 ID 保存在当前标签页；同一工作流内各详情横向并排、每列至少 320px，独立纵向滚动。各列用底部操作栏关闭并恢复相邻列焦点，不新增详情区全局标签。默认宽 365px，沿用历史 `inspectorWidth` 作为未调宽时的默认值；画布显示时上限为窗口的 2/3，隐藏后详情填满工作区。调整布局不写工作区或撤销，也不改画布视角。白板、分组、说明由原入口打开共用 Dialog，关系外观与引用在编辑弹窗处理。左上角选中副工具栏统一承载编辑及红色移除，按显式选中项原子清理节点／说明／关系，分组仅解散；节点删除继续同步清理成员和关联边。Git 详情不接收白板写回调。

`InspectorDock` 用容器尺寸和滚动位置判断左右是否还有内容，溢出时在底部提供方向按钮。按钮只移动详情视窗，不重排、不关闭详情，也不切换分支；滚动位置沿用工作流浏览状态。分支树隐藏原生滚动条但保留滚动容器，以维持拖动、缩放和视角恢复。

Board 可选 `notes` 保存独立人工说明（id、title、text、position），与仓库节点和组共享唯一标识范围；每板最多 200 个，标题 100 字符、正文 2000 字符。说明没有 repoId，不能加入仓库分组或充当 Git 关系端点，服务快照只读取既有仓库节点。可选 `layoutLocked` 只固定位置操作与历史回放；缩放锁定、工具模式、临时选择和聚焦属于画布状态。

`src/lib/board-history.ts` 按白板保存最近 50 次内容快照，包含名称、说明、仓库位置、关系、分组和人工说明；忽略 viewport、layoutLocked、workspace revision、activeBoardId、仓库索引和 Git 状态。`use-workspace` 在内容变更时记录历史，撤销／重做合并到当前工作区后进入相同的串行保存队列，保存冲突仍停止后续写入；新编辑清除该白板重做，刷新不恢复历史。移除仓库节点后撤销仅恢复白板引用，不重新执行任何 Git 操作。

多选移动先将所选组展开到成员集合并去重，应用共同位移和共同限幅；排列将显式选择的分组视为单个边界单元，保持成员间距。React Flow 的单节点焦点与框选后自动聚焦的选择框共用移动和持久化路径，拖动过程仅保留临时位置，结束时原子入历史。临时位置绑定内容来源，历史回放时立即采用保存位置。

Shift 锁轴使用未吸附、未投影的拖动位移。按住时越过 4 屏幕像素后按主方向选轴，直到松开再恢复双轴；预览和释放共用同一约束。边缘自动平移只更新位移，不用旧指针事件覆盖实时按键状态。吸附跳过不可移动的轴，Alt 独立控制是否吸附。

左键框选复用 React Flow 的相交检测和选择框；展开分组的背景不拦截指针，标题仍交互。只在框选期间过滤展开分组与关联线的自动选中事件，保留标题、卡片、连线的单独点选和折叠分组选择。

`src/lib/snapping.ts` 独立计算智能吸附：手势开始冻结实际尺寸、初始位置和可见候选，多选按整体外框、分组按组外框计算，排除移动对象、受其影响的父组与隐藏对象。边缘、中心和同行／同列等间距按屏幕距离匹配，6px 进入、10px 释放，候选排序稳定。`FlowCanvas` 从 React Flow 原始拖动坐标计算同一共同位移，用于预览与最终一次提交；参考线采用世界坐标并跟随当前视角，不接收指针、不持久化、不导出。Alt 临时跳过，键盘微调与布局锁定保持独立。`snappingEnabled` 默认开启，仅保存浏览器偏好。Escape、多触点、触摸／指针取消、窗口失焦或隐藏时回滚手势且不提交历史；忽略尾随位置事件，释放后重建单节点与多选框拖动处理器，保留选择和后续手势能力。

聚焦只过滤显示投影，完整包含的折叠组继续投影外部边；部分成员聚焦时展示对应真实节点。投影变化重新测量动态端口；打开视图之外的节点会退出聚焦。`src/lib/board-export.ts` 使用可见投影与当前 CSS 语义颜色生成独立 SVG（无 foreignObject），连线路径取自实际路由，文本转义；PNG 由同一 SVG 在本机转换，限制最长边 8192 和总面积 1600 万像素。导出不包含仓库路径、凭据、工具栏和未显示详情，用户手动写入可见文字的内容保留。

目前一个数据目录仅供一个 MeGit 进程使用，多页面由同一实例提供服务。多个实例应设置不同 MEGIT_DATA_DIR。

## Git 与真实状态

两个登记的本地仓库可在代码整合连线单独启用 `localMerge`。`/api/boards/:boardId/relations/:edgeId/merge` 校验连线、路径和本地分支引用；审阅使用 Git 的临时备用对象目录读取固定的两端提交，不导入对象或修改工作区。准备时复核两端 SHA 和目标工作区，按固定 SHA 本地导入源提交，不添加远端、不写 `FETCH_HEAD`，以 `--no-ff --no-commit` 进入原生合并。提交或取消与其他目标 Git 写操作串行；通过数据目录 `relation-merges/` 中的会话、原目标分支 SHA、`MERGE_HEAD` 和 `MERGE_MSG` 核对归属。提交需无冲突、无未暂存改动，且暂存指纹与审阅结果相同。若删除／改绑连线导致无法在原窗口恢复，可从目标仓库直接处理 Git 合并；关闭窗口不会取消。该功能不维护项目专用基线或验收记录，不推送。

关系详情通过 `/api/boards/:boardId/relations/:edgeId/history` 按需读取 `integration-history.ts`，沿用本机会话、来源校验及仓库登记路径验证。两端先解析为固定 SHA，后续共同祖先、局部计数／每页 30 条历史及首次包含位置均只读固定对象；后续分页携带原 SHA，引用变化拒绝混合快照。`merge-base --all` 保留全部最佳共同祖先，两侧使用 `--ancestry-path <tip> ^<base>…` 读取共同版本之后的真实祖先路径，计数和分页共用范围；C→D、C→M→T 只展示 C/D/M/T，不展开 M 的范围外父提交 S。兼容字段 sourceOnly／targetOnly 表示该局部范围，不等于全部独有提交；来源待整合继续独立按完整祖先包含关系判断。“首次包含”用单调祖先关系二分查找目标第一父链，不以提交日期推断合并动作，快进时可与来源同号。浅历史、缺对象和无共同历史保留限制，不创建推测关系。`integrationMap` 对已加载节点去重并拓扑排序，仅画真实父子；一般共同版本归来源列，目标最新提交即使是共同版本也优先归目标列，保留一个真实节点、不虚构连接；RelationPanel 用 ResizeObserver 读取并排卡片中心作为两列定位，窄列退回25%／75%。提交详情复用 InfoPopover 的可选胶囊触发器和顶层浮层，原有信息按钮默认行为不变；卡片无提交摘要或重复列表，整合总结提示栏覆盖 integrated／pending／unknown 全部状态，依据按需展开，使用 currentResult 的固定两端 SHA 展示最新提交，与图中角色高亮保持同快照；expanded 传入 IntegrationComparison，仅强调已加载两端，收起恢复，不改变视角。总结帮助靠右，未知原因直接可见；缺失父边可能来自范围裁剪或分页，不承诺加载更多会显示。卡片复用仓库头像、标题与语义外观，不复用写操作表单；完整引用保留在 Tooltip，界面简化前缀。

提交圆点由 `CommitPointActions` 提供屏幕坐标的原生顶层浮层，承接新建分支、历史差异和复制完整 SHA。菜单复用实际图形与设计规范示例，提供浮层互斥、视口避让、键盘／Escape、外点／焦点离开关闭和安静焦点交接；复制异步结果绑定本次打开会话。提交命中区域保持 44 屏幕像素，枝梢与圆点留出间隔。新建确认冻结选中提交和仓库快照，不以刷新后的 HEAD 替换起点；默认不切换。

`createBranch` 的 `COMMIT` 起点模式仅接受完整 SHA，执行前校验对象类型为 commit，且仍可从当前 HEAD 或实际投影的本地／远端引用到达；不接受 tag 对象、不可达对象或任意 revision 表达式。沿用登记仓库、同源／会话令牌、串行队列、expected 状态、分支名及脏工作区保护；此模式禁用 tracking。旧的 HEAD 与完整分支引用模式继续用于远端跟踪等明确入口。

调用使用 `execFile`、参数数组和 `--literal-pathspecs`，不拼接 shell。工作区使用 porcelain v2 / NUL 分隔输出解析，兼容空格、中文、重命名、冲突和空仓库；历史使用带父 SHA 的结构化投影。操作在每个仓库内串行，路径来自已登记的规范化根目录，文件操作对当前 Git 状态重新验证。

分支投影从完整 `refs/heads/` 与 `refs/remotes/` 截取名称，避开同名标签歧义及远端 HEAD 符号别名；记录分支工作树占用和当前工作树的进行中 Git 操作。分支动作使用严格参数协议，携带页面确认的当前分支、HEAD、detached 及目标提交；服务在执行队列内重新读取并校验，过期返回 409。新分支名仅接受字面名称并通过 `git check-ref-format --branch`；起点支持 HEAD、实际列出的完整本地／远端引用，或经可达性校验的 COMMIT 模式；不能传任意 revision 表达式。

创建不覆盖既有分支；远端跟踪使用本地缓存和显式 tracking，无自动联网。切换要求工作区无暂存、未暂存或未跟踪修改，使用 `git switch --no-guess --no-overwrite-ignore --no-recurse-submodules`，保护 ignored 文件且不自动更新子模块。删除前验证目标提交已被当前 HEAD 包含，再使用 `git branch -d` 保留 Git 原生保护；拒绝当前分支和其他工作树占用，不提供强制删除、自动 stash 或历史重写。

`BranchesPanel` 冻结弹窗打开时的确认快照，处理中锁定字段、关闭和重复提交，失败原因留在表单。仓库动作响应先更新状态，再排队刷新白板关系；`snapshotVersion` 丢弃动作前启动但迟到的轮询结果。分支动作不修改白板数据或撤销历史。

源码整合按祖先关系判断；不把复制、cherry-pick 或 squash 猜为已经整合。Git 对象不存在与没有共同历史都返回 unknown。远端数量与本地检查时间、获取时间分别展示；不存在上游时用 null。

状态刷新与轮询只读取本机。显式“获取”共用参数 `git fetch --all --prune --no-recurse-submodules`，命令预览与服务执行保持一致；成功联系远端后清理已删除分支的远端跟踪引用，不删除本地分支或已合并历史。分支树工具菜单与当前分支详情均提供入口，动作后重新读取快照和图形；远端失败沿用可见错误，不把本机缓存误标为实时状态。

状态桥快捷操作与比较分离。写入入口使用已保存的白板／连线及已确认的端点、仓库、规范分支引用、提交编号，在目标仓库队列内复核。上游同步只允许同一登记仓库当前检出的分支及其准确上游引用；推送同时检查读取／写入地址及远端分支版本。两个登记仓库必须在关系上显式设置 `localIntegration`：仅从登记的本机路径导入固定提交对象，不设置远端、更新跟踪引用或写 `FETCH_HEAD`；重新检查来源、目标和工作区，再仅快进当前检出的干净目标分支，不覆盖忽略文件或递归更新子模块。

fetch 若返回 `couldn't find remote ref refs/heads/`，使用稳定错误 `remoteRefMissing` 解释获取规则请求了不存在的远端分支，保留脱敏诊断。不得自动扩大用户配置的定向获取范围；需明确修正规则后重试。分支树工具动作错误放在面板级可见区域，不依赖选中分支详情。

差异禁用外部 diff 和 textconv，限制响应大小；未跟踪文件只读取限定字节，仓库外符号链接拒绝预览。大型仓库首版采用分页历史、按需差异、当前白板定期轮询，后续可引入可取消请求、文件监听和更细的状态缓存。

## 本机边界

`Repository.logoPath` 是可选的仓库内相对图片路径，随工作区保存并跨白板共用，缺失字段继续使用默认图标。`server/repository-images.ts` 按需浏览单层目录（每页 100 项）并读取最多 1 MiB 的支持格式，复用登记仓库、同源和会话校验；路径与 realpath 双重限制仓库范围，拒绝 Git 内部路径与越界链接。仅在头像或仓库路径变化时校验图片内容，已保存图片丢失不阻塞其他白板修改。

`RepositoryAvatar` 共用缓存与错误回退，`RepositoryAvatarDialog` 从详情标题图标打开，预览和目录异步结果绑定当前选择，取消不写数据。头像以经过校验的 data URL 交给 `<img>`，SVG 不注入 DOM；独立白板导出只内嵌支持的图片 data URL，不携带本机图片路径或外部链接。

服务只监听 127.0.0.1。校验精确 Host／同源 Origin／Fetch Site；会话随机令牌由同源接口建立，后续 API 要求自定义请求头，不开启 CORS。API 不返回远端地址中的凭据；Git 错误进行常见令牌脱敏。不能将此服务直接暴露到公网。

## 提供者扩展方向

当前关系类型与 Git 状态分离。后续可引入 RelationProvider / DeliveryProvider，返回带时间、来源、提交 SHA 的状态证据。MeWiki 的公共基线和维护检查、GitHub CI 结果与实际部署版本应分别接入，不能由连线、推送成功或构建成功推断部署成功。

## Git 命令与事件提示

`shared/git-commands.ts` 共用主要参数构造及执行固定选项，服务端保留原校验后使用参数数组执行，前端由 `GitCommandPreview` 生成 PowerShell 字面展示，不执行命令字符串。`RepoState.pushTarget` 仅投影真实配置中已登记的远端名称及分支引用，不返回 URL。创建确认直接复用待提交 action，随名称、跟踪与切换选项更新；未填写名称的入口明确使用模板。

`CommitEvent` 根据具体提交显示说明、作者、Intl 时间、父提交和引用；`rootUnconfirmed` 避免把浅克隆的空父历史误当真实初始提交。通用操作说明集中在地图帮助。Tooltip 默认读取 `--tooltip-open-delay`，兼容生产 CSS 的秒／毫秒形式；键盘立即显示，菜单方向导航优先于提示内部滚动，PageUp／PageDown 仍可阅读长提示。

## 提交优先的工作区与 HEAD

`CommitComposer` 复用于工作区与当前 HEAD 的详情卡片，显式接收 RepoState、草稿、忙碌状态及既有 GitAction 执行回调。工作区把远端同步集中在标题栏下方的一行，文件双栏取代紧凑汇总行；各栏标题复用批量暂存按钮，两份列表的滚动位置按当前标签页分别恢复，提交栏固定在底部。RepositoryPanel 继续统一持有每仓库草稿和 busyRef，防止多个入口重复执行；工作区打开时卡片中的编辑器暂时隐藏，避免重复可访问字段，关闭后恢复同一草稿。提交成功清空草稿，失败在操作处显示格式化错误并保留输入；暂存／取消暂存使用当前文件集合，命令预览复用 actionArguments。HEAD 卡片在图形引用和快照当前分支／完整 SHA 一致时才显示提交入口，刷新时禁用动作。冲突阻止提交，不自动暂存或推送。设计规范示例用同一组件仅更新内存，不访问真实仓库。

提交操作通过稳定的 onOpenChange 回调通知所在地图，SVG 原始圆点／HEAD 方块仅在菜单打开期间以中心为原点放大两倍；透明命中目标尺寸与图形尺寸分离，关闭或卸载清理选中状态。局部气泡使用独立滚动层和外侧尖嘴，固定坐标根据数量标签中心与视口限幅定位。

流程线选中时，useSelectedConnectionPorts 从 React Flow 的已选可重连边提取本节点端口，步骤与 RepositoryPorts 共用选择判定；共用仓库端口同步放大当前可见类型，同边输入／输出分离时仅放大实际端口。CSS 围绕原中心按原形缩放两倍，重连 updater 仅保留透明拖动命中，不改变连线路由、端口偏移或持久数据。设计规范的真实连接点示例支持点选边展示相同状态。

仓库节点由 `RepositoryCard` 显示两行身份信息和单行暂存／提交区；`useRepositoryActions` 与仓库详情共用原 `viewKey.draft` 浏览草稿，并按仓库 id／路径共享同步忙碌锁。成功写操作立即回传状态、使旧快照失效并刷新，提交成功才清空草稿；失败保留输入且在操作区显示。AI 提交说明仅显示可聚焦的禁用占位，不请求 AI。操作区阻止节点拖动与键盘冒泡。设计规范用相同卡片和局部虚构状态演示，不请求 API，偏好示例显式关闭真实 AI 配置加载。
