# MeGit 产品设计规范

版本 1 · 2026-11-16。用于新增页面、白板工具、仓库操作和检查器。与[配色规范](COLOR_GUIDELINES.md)、[主题与国际化](THEME_I18N.md)、[界面原则](UI_GUIDELINES.md)一起使用。

启动 MeGit 后访问 [真实组件示例](http://127.0.0.1:4317/design-system)；[品牌色卡](http://127.0.0.1:4317/brand/color-palette.html)与示例页互相链接。示例复用产品组件与浏览器偏好，不挂载工作区、不调用仓库 API，不写入白板。

## 1. 页面骨架

MeGit 是多仓库流程白板。导航、画布与上下文检查器构成固定骨架，关系通过位置和有向连线表达。

| 区域         | 内容与规则                                                                                                       |
| ------------ | ---------------------------------------------------------------------------------------------------------------- |
| 导航         | 展开面板与 Ribbon 共用结构和背景；展开时显示完整 Logo，帮助在右上角；折叠时显示独立图形。偏好设置留在底部。      |
| 工作区       | 画布为主，当前白板标题与工具组成局部操作区域；高频动作可直接操作，低频动作进入菜单。导航开关留在工作区左侧入口。 |
| 上下文检查器 | 仓库 Git 功能与关系比较横向并排；每列共用标题与关闭入口，白板编辑通过画布弹窗完成。                              |
| 表单／弹窗   | 标题 → 必要字段 → 字段反馈 → 底部动作。主要动作位于右侧，取消在其左侧。                                          |
| 全局反馈     | 保存与会话错误持续显示在工作区，必须能辨认是否已保存；临时成功提示说明具体对象与结果。                           |

新增索引或列表页时采用“标题与主操作 → 必要筛选 → 内容与状态”的顺序；只有出现相应需求时才添加筛选、分页或概览。每个操作区域保留一个主要动作，标题和辅助说明不重复同一件事。

桌面导航宽 212px，Ribbon 宽 56px，导航品牌行 44px，检查器默认宽 365px。窄屏导航改为 256px 抽屉，最多占视口宽减 56px，为品牌、版本与触控帮助／关闭入口留出空间；检查器覆盖画布。英文和长名称不能挤掉主要操作。连线路由、节点坐标和导出几何继续由白板模型管理。

右侧为 Git 多详情区域，左边界可拖拽调宽，上限为窗口的 2/3；默认 365px、常规最小 320px，窄窗口仍受上限约束。每列最小 `--inspector-card-min` 320px，空间充裕时平分，放不下时内部左右滚动，各列独立纵向滚动。直接显示各列标题与关闭入口，不增加区域标题、标签栏或箭头导航；标题长名称完整换行。仓库与关系面板不包含白板编辑、外观设置或移除底栏。

重复打开仅定位已有 Git 详情。未关闭的仓库保留输入草稿、内页和内容状态；点击空白只取消选择，删除对象仅清理对应详情，切换白板关闭旧详情。边界支持左／右键增／减 16px、Shift 步长 64px、Home 最窄、End 最宽、双击恢复默认。滚动区域可聚焦并用键盘横向浏览，平滑滚动尊重减少动态效果；关闭时焦点返回相邻列标题操作或工作区。白板、分组、说明编辑在共用 Dialog 中完成，沿用焦点、Escape、双语与两主题规则。

导航展开与折叠时，品牌图形保持同一实际尺寸；展开态 Logo 右下方显示中性版本徽标，底部只保留操作入口。画布左上开关、相邻编辑工具与右侧操作栏使用同一按钮尺寸和内边距：顶部各留 12px，4px 内边距、1px 边框；桌面按钮 32px、单行外框高 42px，触控按钮 44px、单行外框高 54px。编辑工具通过共用尺寸 token 避让，窄屏换行。

## 2. 基础 Token

颜色只在 `src/themes.css` 定义，以 `public/brand/palette.json` 为登记目录；组件通过语义 token 使用颜色。共用尺寸、文字和圆角放在 `src/tokens.css`，两主题共用。

| 用途     | Token 与取值                                                                   |
| -------- | ------------------------------------------------------------------------------ |
| 间距     | `--space-1/2/3/4/5/6/8`：4 / 8 / 12 / 16 / 20 / 24 / 32px                      |
| 字号     | `--text-micro/caption/dense/body/heading/title`：11 / 12 / 13 / 14 / 16 / 20px |
| 行高     | `--leading-compact` 1.4；`--leading-body` 1.6                                  |
| 字重     | `--weight-regular/medium/strong`：400 / 500 / 600                              |
| 圆角     | `--radius-small/control/panel`：4 / 6 / 8px                                    |
| 控件     | `--control-small/compact/default/touch`：28 / 32 / 36 / 44px                   |
| 固定区域 | `--header-height`、`--navigation-width`、`--ribbon-width`、`--inspector-width` |

密集工作台默认 13px，表单同样使用 13px；14px 用于需要连续阅读的正文，11px 仅用于非关键元信息。正文不能通过降低透明度变成不可读的灰字。标题主要靠字号、字重与间距区分。

标准控件最小高度 36px，紧凑控件 32px，小图标 28px。粗指针环境中基础按钮和表单扩大到至少 44px 命中目标，输入字号 16px；图形画布仍需单独检查缩放后的操作目标。高度是最小值，允许英文和长文本换行，禁止固定高度裁掉文字。

颜色职责保持稳定：中性色组织结构，深蓝／亮青表达交互与焦点，绿色表达成功，登记的功能色表达警告和危险。文字对比度至少 4.5:1，必要控件边界至少 3:1；选中、错误和状态同时有文字、图标或结构反馈。层级优先使用表面与细边框，阴影用于浮层与覆盖面板。

## 3. 共用组件契约

优先复用 `src/components/` 中的实际组件。表格、日期、复杂筛选和分页等在产品需要时补充。

| 组件            | 默认规则                                                                                                             | 必查状态                                                                                                    |
| --------------- | -------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| `Button`        | 默认 `type="button"`；提交显式 `type="submit"`。主要／普通／危险三个语义，标准／紧凑两种密度。图标通过 `icon` 传入。 | 悬停、聚焦、禁用、加载、长文本。`busy` 阻止重复提交并设置 `aria-busy`；异步按钮持续传布尔值，预留图标空间。 |
| `IconButton`    | 必填翻译后的 `label`，内置 tooltip 和无障碍名称；默认 32px，小号 28px。                                              | 悬停、键盘聚焦均可看到说明；Escape 关闭。不要再包一层 Tooltip，必要限制不能只通过禁用按钮的 tooltip 解释。  |
| `Field`         | 一个可见标签、一个原生输入／选择／文本域，可选 hint 和 error。自动生成唯一 id 并关联标签、说明与错误。               | 错误设置 `aria-invalid`、`aria-describedby` 与可见反馈。旧错误在相关字段改变后清除，多个实例的 id 不冲突。  |
| `PanelHeader`   | 对象图标、标题、标题操作和关闭保持同一顺序；仓库信息按钮位于关闭左侧。                                               | 长名称完整换行；标题操作不挤掉关闭；明暗主题不改变结构。                                                    |
| `Dialog`        | 原生模态对话框、关联标题、焦点约束与关闭后的焦点恢复。                                                               | 空表单、错误、窄屏和键盘；异步提交中禁用关闭入口、背景关闭与 Escape，完成后恢复。                           |
| `Tooltip`       | 普通提示保持简短；Git 详细说明用标题、含义和结果，不包含交互。                                                       | 悬停、聚焦、Escape；详细说明可移入阅读，问号可点击固定；必要状态和错误始终可见。                            |
| `InfoPopover`   | 非模态信息浮层承载低频原始资料，复用顶层显示、双主题和浮层互斥。                                                     | 外点／Tab 不抢焦点；Escape 和关闭返回入口；内部滚动、长路径、嵌套说明与窄屏完整显示。                       |
| `InspectorDock` | Git 详情保持挂载，各列标题关闭，边界调宽和内部横向滚动。                                                             | 最大窗口 2/3、独立草稿、长标题、滚动和关闭焦点、减少动态、窄屏及两主题双语。                                |

组件负责展示和可访问性，业务校验与 API 状态由使用方维护。不要为一次性布局增加复杂配置层，不复制组件制作另一套主题。

`Dialog` 可选标题动作 `headerActions`、标题拖动 `draggable` 和显式关闭 `persistent`。只有长期学习等明确需要的场景启用显式关闭；常规表单继续支持背景和 Escape，异步忙碌保护不变。拖动与键盘移动共用限幅，窗口变化后保留标题和关闭入口；移动时收起旧坐标 tooltip。标题双击或移动按钮 Home 居中，方向键每次 16px、Shift 为 40px。

功能动画提示通过 `Button`／`IconButton` 的可选 `learningDemo` 接入，复用课堂原帧及双语短提示；不再包装第二层 Tooltip。悬停 500ms 打开，键盘聚焦立即显示；动画每 1400ms 推进一帧，最多四帧，只播一遍并停在结果。静态模式与减少动态直接显示海报帧。预览默认宽 380px、图形高 300px，仍受视口 8px 边距与内部滚动限制；内容变化自动重定位。关闭即卸载，无交互按钮或真实 Git 调用。`/design-system` 的“功能演示提示”提供真实可切换示例；完整契约见 [Git 功能演示接口](GIT_LEARNING_MEDIA.md)。

白板组件的移除统一位于左上角选中副工具栏，支持单项与多选；组仅解散且保留成员。Git 区域和白板编辑弹窗不显示移除底栏。删除与移除入口使用 `Trash2` 图标和明确名称，复用 `Button variant="danger"` 或 `IconButton variant="danger"`；菜单项使用同一危险语义。默认态即可辨识危险色，悬停使用危险浅色表面，不只在悬停时变红，也不能只靠颜色解释操作。

确认依据实际后果设置：白板节点、关系、分组和说明可在本次页面会话撤销，直接操作并注明保留范围／可撤销；移除整个工作流会清理其内容与历史，必须显示对象原名、全部移除范围和无法撤销说明，再由明确的危险按钮确认。本机仓库文件和其他工作流的保留范围保持可见。Git 分支继续使用现有确认和服务端安全检查。

破坏性确认打开后，初始焦点放在“取消”；Enter 不直接执行删除。需要指定初始焦点的控件标记 `data-dialog-initial-focus="true"`，`Dialog` 在显示后统一聚焦，避免隐藏弹窗中的 React `autoFocus` 失效。取消、关闭、背景和 Escape 均不修改内容，关闭后恢复有效触发器。异步真实操作处理中禁止关闭与重复提交，错误在窗口中持续显示。

临时浮层共用以下交互规则：

- `Tooltip` 同时只显示一个，鼠标悬停或主动键盘聚焦可查看；点击／触摸激活、点击外部、滚动、窗口失焦或 Escape 收起。捕获阶段处理激活，节点按钮阻止冒泡也不能留下提示。自动进入对话框或关闭后恢复焦点不触发提示；触摸不模拟悬停提示。
- 所有 `Tooltip` 统一使用浏览器顶层浮层，跨越导航、画布和滚动裁切容器，原生模态内仍完整可见。空间不足自动换向，与窗口边缘至少保持 8px；保持同样的关闭与焦点规则，不按调用处选择 portal 或修改层级。
- `PopupMenu` 用于工作流选项、导出和排列；同一时间只保留一个菜单。外点、焦点移出、Escape、执行动作、打开模态、外部滚动、窗口变化或失焦均收起，菜单内部滚动不关闭。Enter／空格或方向键可进入，方向键和 Home／End 遍历可用项，Tab 按自然顺序离开。
- 关闭时保留有效焦点：Escape 和执行动作返回触发按钮；外点／Tab 不抢走新目标的焦点；滚动或窗口变化关闭正在键盘浏览的菜单时返回触发按钮。弹窗从菜单打开时记住仍存在的菜单触发器。
- Escape 只处理当前最上层临时内容。主动查看的 tooltip 先关闭，再次按键关闭菜单、弹窗或导航；自动恢复焦点不会生成需要多按一次 Escape 的新提示。异步提交中的模态仍禁止意外关闭。检查器和持久展开的比较依据沿用各自规则。

## 4. 列表、状态和长内容

- 仓库详情以向上生长的分支树为默认入口，不使用工作区／历史／分支次级标签栏。树干是比较视角，双圆环是当前代码位置；合流按真实父子关系绘制，同点引用共用节点。连续历史可压缩，但不能抹掉真实分叉和合流；缺失父历史用虚线并附可见原因。
- 点选枝梢后在区域内渐进展示分支详情，Escape 收起并安静返回枝梢。低频引用、完整 SHA 和目录收进「i」，操作和未知原因保持可见。文件与历史按需打开模态；嵌套差异只关闭最上层窗口，仓库草稿留在根组件。图形缩放和滚动不改变白板，窄屏放不下时允许内部浏览，宽面板按实际图宽居中。
- 分支地图不设常驻树干选择行，缩放、居中、帮助、新建及工具集中于地图右上角；“更换比较树干”收在工具菜单，按需选择并确认，不切换工作区代码。菜单限制在地图可用高度内，矮窗口可内部滚动。点选详情以分支图标、完整名称及 HEAD／树干标记建立层级，比较、同步和工作区入口分区呈现，原始资料仍位于「i」。
- 比较树干、真实合流、HEAD 双圆环与枝梢点选的说明集中在地图右上角「?」，各详情列不设常驻底部图例或教学提示。帮助沿用悬停、键盘聚焦、点击固定和 Escape 规则，`/design-system` 复用同一帮助资源；历史边界、浅克隆、加载与错误仍直接显示。
- 图形视口中的滚轮和双指缩放仅改变地图，范围 50%–200%，以鼠标位置为锚；连续正反向缩放不跳动、不回到原树干。水平／Shift 滚动与滚动条保留浏览能力，详情正文滚动不缩放地图；按钮和键盘入口保留，触控工具至少 44px。`/design-system` 使用同一地图控件与树干选择窗口演示。

- 仓库身份统一使用 `RepositoryAvatar`：未设置或图片不可用时回退默认图标，项目 Logo 保持原比例和原颜色。18／28／32／72px 尺寸使用 `src/tokens.css`，同一仓库跨白板共用；头像不替代名称、分支或必要状态。详情标题图标通过 `PanelHeader.iconAction` 进入设置，悬停和键盘聚焦提供说明。设置窗口按需浏览目录、预览后确认，错误持续可见，取消不修改；粗指针文件行至少 44px。`/design-system` 提供真实头像、默认、失败回退及标题动作示例，不读取仓库。
- 仓库列表先显示名称，再显示本次判断所需状态；文件列表保留文件名与路径，常用暂存操作贴近对应记录。
- 同类列表共用密度与对齐方式；数量使用 Intl／i18next 复数。数据多时再引入分页或虚拟列表，不能一次请求全部 Git 历史。
- 状态使用“文字 + 颜色”，必要时增加图标。未读取、不可用、无共同历史、待整合与已包含必须区分，不能将未知当作成功。
- 检查器对象名称完整换行。列表名称可以省略，但必须能通过可聚焦记录、详情或路径原文查看完整内容。差异、提交说明、仓库名和路径保留原文。
- 首次使用、查询无结果和加载失败使用不同反馈。空态给一个适合当前对象的下一步；失败保留重试或可执行说明，加载不能显示为“没有记录”。
- 移除白板对象和 Git 操作的含义必须区分，避免让用户误以为删除本机仓库；有数据损失风险的动作使用明确对象和危险语义。

## 5. 表单与字段错误

字段有稳定可见标签，placeholder 只放示例。短提示放字段附近，冗长解释按需展开。文本输入遵循现有字符限制；必填内容先 trim 校验，用户正文不擅自改写。

提交后把错误放在相关字段下方，关联到控件，并聚焦第一个错误字段。分组成员错误关联整个 fieldset 及复选框，焦点进入首个可选成员。提交级错误保持在当前表单内，不能只显示短暂 toast。

异步提交开始后锁定提交和相关字段，显示加载并阻止重复操作。添加仓库检查失败后恢复输入，将错误与路径关联；修改路径立即清除过期错误。提交前后的宽度和主要动作位置保持稳定。

## 6. 反馈与恢复

反馈优先说明“对象、结果、下一步”。例如“某仓库：文件已暂存”。成功提示可以自动收起；失败、冲突和未保存状态保持可见，操作错误应说明失败原因。

| 场景                     | 产品行为                                                                                                              |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------- |
| 自动保存进行中           | 显示“保存中”；按同一串行队列提交，期间的新编辑接着保存。                                                              |
| 连接／保存传输失败       | 保留页面内未保存修改并停止队列，提供“重试保存”；人工重试继续原队列，不变更 revision，不自动循环。成功前保持页面打开。 |
| 版本冲突／会话或校验失败 | 停止后续写入，不自动重试、不覆盖服务端；保留当前未保存内容，显示原因和刷新入口。刷新会离开页面内未保存状态。          |
| 字段校验失败             | 字段旁持久显示，错误字段可被读屏与键盘识别。                                                                          |
| Git 操作完成             | 提示仓库对象与实际操作结果。推送成功不推断部署成功，已包含不推断已测试。                                              |
| Git 操作失败             | 按当前语言解释稳定错误代码，保留脱敏后的 Git 原始诊断。                                                               |

保存失败时阻止进一步修改和历史回放，防止用户误以为新操作已保存。离开页面仍使用浏览器未保存提醒。人工重试不创建历史记录，也不重新执行 Git 操作。

## 7. 白板交互

- 选择、悬停与上下游强调各有层次；选择结果可在检查器查看，关键反馈不能仅靠颜色。
- 选择模式用于框选，平移模式用于移动视角；工具显示当前状态。Shift／Ctrl 扩充选择，Escape 退出临时状态，输入字段中的快捷键不触发白板命令。
- 布局锁定约束位置与历史回放；缩放锁定约束比例。锁定状态和禁用操作可以辨认，两个锁彼此独立。
- 连线的方向、端点和引用应清楚。线型只决定画法，整合状态来自 Git 证据；比较依据按需展开，无法核对的原因保持可见。
- 分组折叠保留真实仓库与关系；多选、整体移动和排列按一次意图原子记录。组与人工说明不能伪装成 Git 仓库或提交证据。
- 自动吸附默认开启，工具栏磁铁可切换并记住浏览器偏好；边缘、中心和同行／同列相等间距显示对应参考线。进入距离 6 屏幕像素、释放距离 10 像素，缩放后手感一致。多选与分组按整体外框吸附，保持内部布局，隐藏对象和变化中的父组不作参考。Alt 临时跳过，方向键微调保持原规则；一次拖动只记录一步撤销，参考线不存储、不导出。Escape、双指介入、触摸取消或窗口失焦时回滚本次手势，清理参考线且不产生历史；释放触点后保留选择并可继续拖动。
- 撤销／重做只回放当前白板内容；视角、偏好、Git 操作与仓库磁盘内容不进入白板历史。刷新清空会话历史。
- 聚焦过滤显示而不删除数据；导出使用当前主题和可见投影，不包含工具栏和仓库路径等隐藏详情。
- 打开／关闭检查器、展开／收起导航只改变可视区域，保留用户当前平移与缩放。首次显示、新增对象、主动聚焦和“适应白板”仍按原规则定位；不因窗口容器变化自动适应白板。

## 8. 示例与验收

`/design-system` 展示实际尺寸、按钮加载／禁用、图标 tooltip、受限容器中的提示、必填错误与焦点、长名称面板、状态和空态，并使用真实 `InspectorDock` 演示无标签 Git 双详情、独立草稿、调宽和滚动。右上角偏好设置复用产品实现，可切换明暗与中英文；输入的用户内容不会随语言改变。

每次用户可见变更都应检查：

1. 暗黑与明亮：正文、状态、控件边界、焦点与图形清楚可辨。
2. 中文与英文：标签、无障碍名称、错误同步；英文展开和用户长内容不裁切。
3. 键盘：可到达主要入口，焦点可见；tooltip 支持 Escape；弹窗打开、关闭后焦点合理。
4. 窄屏与粗指针：390px 无页面横向溢出，主要动作可用；表单、弹窗和图标具有可点击空间。
5. 状态：默认、悬停、选中、禁用、加载、错误、无数据和长内容均有适合场景的反馈。
6. 工程检查：`npm run check` 和相关独立数据目录的 `npm run test:e2e`；证据写入忽略目录 `.megit/verification/`。

先把重复做法补进共用组件与示例，再更新规范。新增颜色先登记色卡与两主题；新增文案同步两种语言；新增组件覆盖当下真实需求。

## 9. Git 图解课堂

帮助标题右侧提供“学习 Git”。课堂采用课程导航 → 一句问题 → 示意命令 → 图形 → 一句结果 → 播放控制的顺序；文件、暂存和提交以卡片分区，提交图的箭头指向父提交，分支与 HEAD 使用独立标签。普通自动合并必须使用互不重叠的文件修改；冲突课保留暂停、编辑、暂存和提交各阶段。必要丢弃风险在当前步骤可见，不能只靠颜色或 tooltip。

默认不自动播放；支持上一步、逐步执行、跳转、播放／暂停和重播。解释动作使用 `--motion-explain` 600ms，只改变 transform／opacity，尊重减少动态偏好；高频控件不额外添加动效。离开窗口、切课或手动跳转暂停。所有内容使用虚构内存状态，与真实仓库隔离。

桌面最大 1120 × 780px，矮屏收紧卡片与图形间距；窄屏课程横向浏览、远端三种引用改为横向历史行，不依赖精细悬停。图解可聚焦滚动；读屏替代文本包含 HEAD、分支目标、父提交和三个远端状态。`/design-system` 复用同一课堂，验收双主题、双语、390px 触控、减少动态、连续拖动限幅、键盘移动和显式关闭后的焦点恢复。
