# MeGit 品牌配色实施计划

目标：从已确认的 SVG Logo 提取准确原色，制作可查看与复用的色卡，把配色规则接入后续开发约定，并应用于现有两套主题。

范围：在「排查觅维本地服务启动失败 (2)」任务完成后接手；只调整品牌与主题基础，不新增无关功能，不改动用户白板或 Git 仓库。

1. 读取 SVG 中的填色、渐变与节点色，区分 Logo 原色、可访问色阶、中性色和必要功能扩展色。
2. 编制 `public/brand/palette.json` 作为设计交付数据，覆盖明暗主题的全部语义颜色；在 `src/themes.css` 维护运行时颜色，并用校验约束两者一致。
3. 先添加有意义的校验：SVG 原色来源、配色文件与主题一致、正文／状态／焦点等对比度；先验证当前缺少色卡时失败，再完成实现。
4. 以少锚点 SVG／PNG 和可切换明暗、复制色值的独立色卡展示规范；文档说明颜色用途与限制，避免在正文中滥用高亮品牌色。
5. 更新 `AGENTS.md`、主题规范、界面规范和规则入口，让未来界面使用同一套语义 token。
6. 完成 `npm run check`、独立数据目录下的 Edge 场景、色卡交互与两主题视觉核对；重新构建并核对正式页面与用户白板完整性。证据写入忽略的 `.megit/verification/`。

按照当前会话授权连续实施，不自动提交或推送。
