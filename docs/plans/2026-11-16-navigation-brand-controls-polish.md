# 导航品牌与画布控件对齐

用户要求移除侧栏底部本地服务行，将版本号放到 Logo 右下方作为小徽标；统一展开与折叠的品牌图形大小，并让左侧折叠开关与右侧操作栏同尺寸、顶部对齐。

- 保留 84px 完整 Logo。折叠图形按完整标志中图形的实际缩放比例计算尺寸，避免为独立图形使用另一套 34px 尺寸；保留 SVG 路径与透明背景。
- 版本读取产品版本，展开导航与窄屏抽屉中用中性徽标贴近 Logo 右下方。提供中英文版本名称；折叠 Ribbon 保留紧凑图形，版本信息在展开后查看。
- 窄屏抽屉宽 256px，同时限制为视口宽减 56px；版本徽标与 44px 帮助／关闭按钮不重叠。
- 左右浮动控件共用顶部间距、内边距、边框、圆角与按钮尺寸。桌面按钮 32px、含外框 42px；触控按钮 44px、含外框 54px。既有编辑工具根据同一尺寸避让。
- 相邻的编辑工具也使用同一 32px／44px 按钮、4px 内边距和 18px 图标，桌面首行与开关对齐。
