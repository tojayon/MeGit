# 顶部帮助入口与暗黑 Logo 轮廓

**目标：** 展开导航的帮助入口移到 Logo 右侧并靠右对齐；顶部行由 64px 收紧为 44px；改善暗黑背景上的图形识别。

**设计：** 顶部使用带双语 tooltip 的帮助图标按钮，窄屏与关闭按钮并列。折叠 Ribbon 保留底部帮助入口，避免挤占 Logo。暗黑主题给图形增加柔白细轮廓，导航实际尺寸下约 0.5px；明亮主题轮廓透明。沿用透明容器、固定品牌色、原始矢量路径与锚点。
