# MeGit 分组与上下文白板实施计划

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 落实用户确认的前四项白板改进：仓库分组、可配置连线路由、精简仓库节点、按对象显示的检查器。

**Architecture:** 在版本 1 白板中增加可选的平面分组及连线路由／端口字段，旧文件继续有效。节点始终保存绝对位置；分组边界由成员位置计算，整体移动原子更新成员，折叠只改变展示，跨组边临时映射到分组，真实关系端点保持不变。复用现有串行自动保存、Git 操作面板、主题语义色与双语资源。

**Tech Stack:** React 19、TypeScript、React Flow 12、Zod、Vitest、Playwright / Edge。

## 范围与交互

- 平面分组有名称和成员；一个仓库节点至多属于一个组。创建与编辑通过可访问的复选表单；分组标题可拖动、可键盘移动，支持折叠和解散，解散保留仓库、位置与关系。
- 组边界自动包围成员。折叠保留所有坐标，隐藏内部关系，跨组关系保留各自身份和真实 Git 状态；选中侧栏的隐藏仓库会展开其分组。
- 连线可选圆角折线、直角折线、曲线、直线，四边均有输入／输出端口；旧关系默认圆角折线、右出左入。选中仓库强调可达的上下游路径，方向箭头跟随线色。
- 节点首层展示名称、分支、修改／冲突／不可用及非零同步数量；路径、完整 SHA 和远端细节进入原仓库检查器。
- 检查器支持仓库、关系、分组和白板。默认收起，有明确工具入口；选择对象后打开，点击背景时切到白板内容，关闭后可重新打开。窄屏保留关闭入口。
- 本批不引入嵌套组、绘画、标注、对齐分布或撤销重做，不主动改造用户现有布局或生成示例数据。
