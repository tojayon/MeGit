# 移除入口与删除确认

## 范围与规则

统一工作流、仓库节点、关系、分组、人工说明和本地分支的移除入口。保留既有白板撤销、Git 安全协议和用户数据，不添加文件删除、强制删除或批量清空能力。

- 入口采用垃圾桶图标、明确名称与现有双主题危险 token；图标按钮默认态也显示危险色。
- 白板节点、关系、分组与说明支持本次会话撤销，继续直接操作；说明保留范围及撤销能力。
- 整个工作流无法通过白板历史恢复，二次确认展示名称、移除范围与保留范围。默认焦点在取消，支持 Escape 和背景取消；确认只影响指定工作流，保留至少一个工作流。
- 本地分支沿用现有确认、冻结状态快照、防重复、未合并／占用保护；取消默认聚焦。
- 所有文案同步中英文，危险样式仅使用已有语义色；真实组件示例补齐危险图标按钮。

## 验证

先用 Edge 回归复现缺少图标，再检查确认前无修改、取消／Escape／背景／默认 Enter 的安全行为、焦点恢复、指定工作流隔离及真实临时仓库保护。验证四类可撤销移除和关联内容恢复，覆盖暗黑中文与明亮英文窄屏。完成后执行 `npm run check` 和相关 `npm run test:e2e`，记录到 `docs/VERIFICATION.md`。
