# Git 图解学习面板实现计划

**目标：** 从使用帮助右上角打开可拖动、主动关闭的 Git 学习模态，用动画和图形讲清基本操作，不堆叠说明文字。

**结构：** 共用 Dialog 增加可选标题动作、拖动与主动关闭模式，默认行为不变。独立的学习数据描述七组可回放场景；React 与本地 SVG 展示工作区、暂存区、提交、分支指针和远端引用。所有场景仅使用内存模拟，不调用 Git 或工作区写接口。

**技术：** React、TypeScript、CSS transform／opacity、原生 dialog、i18next、Vitest、Edge Playwright；复用品牌语义 token 与基础按钮。

1. 先增加课程语义、窗口限幅和入口的失败测试；保存既有实现。
2. 建立七组课程：暂存与提交、快照、分支切换、双亲合并、远端同步、撤销、冲突。重点验证暂存是复制快照、切分支不创建提交、fetch 不改本地分支、revert 保留历史。
3. 实现图形教学、逐步操作、播放／暂停、上一步、进度跳转与重播。每步仅一个短提示及命令；播放离开页面暂停，尊重减少动态偏好。
4. 共用窗口提供标题拖动、键盘移动／居中、视口限幅与大小变化恢复。学习窗口只通过关闭按钮退出，保留原生模态焦点约束；关闭后回到帮助中的学习入口。
5. 同步中英文与明暗主题，在 /design-system 加入同一学习窗口示例；检查窄屏内部滚动、触控、图形语义与 tooltip。
6. 运行 npm run check 与独立数据的相关及完整 Edge 回归，查看真实截图，更新使用说明与验证记录。保留用户白板和全部已有改动，不提交或推送；发布遵循现有进程与数据核验，不规避先前审批拒绝。

状态：已完成。七组课程共 34 步，教学语义、拖动限幅、触控、减少动态、显式关闭及焦点恢复均已验收。最终 `npm run check` 通过 107 项单元／接口测试；整合已发布帮助功能后的完整 Edge 回归 89 项通过，最后调整触控命中区域后相关 15 项复核通过。已通过正常前端构建更新当前本机预览，保留原服务进程和已发布功能；五种正式主题／语言／尺寸视图核验通过，真实白板哈希不变。证据见 `.megit/verification/git-learning/`。
