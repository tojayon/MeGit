# Git 详情渐进式披露与帮助 Implementation Plan

> **For Codex:** 沿用用户指定的信息入口直接实现，保留已有改动与真实白板，不提交或推送。

**Goal:** 将低频仓库原始资料收进标题栏信息浮层，为 Git 详情提供面向初学者的按需说明。

**Architecture:** 共用 PanelHeader 支持标题操作；非模态 InfoPopover 复用顶层浮层、互斥及安静焦点规则。Tooltip 支持结构化说明，HelpTip 提供悬停、键盘和触摸点击查看。仓库信息只使用现有本机状态，不新增 API 或 Git 写操作。必要状态与错误保持可见。

**Tech Stack:** React、TypeScript、原生 Popover、i18next、双主题语义 token、Playwright／Edge。

1. 在独立测试数据中复现路径常驻、缺少信息入口和详细 Git 说明。编写信息浮层与帮助的行为验收，确认旧版失败。
2. 实现共用信息浮层、详细 Tooltip 与 HelpTip；验证外点、Escape、互斥、焦点、长路径、窄屏和触摸。
3. 仓库路径、完整 HEAD、远端名称、跟踪及检查／获取时间移入信息浮层。常态保留当前分支、修改、同步数量、操作和缺少跟踪等限制。
4. 仓库工作区／历史／分支、暂存／提交、获取／拉取／推送、关系与差异提供简洁标题和通俗详细解释；原始用户资料保持原样。同步中英文、真实组件示例与规范。
5. 运行 npm run check 和相关 Edge 场景，复审、核对双主题及窄屏；更新验证记录，以正常构建更新正式页面，仅在允许时重启已核实的 MeGit 服务。

状态：已完成。`npm run check` 通过，106 项单元／接口测试和 85 项 Edge 场景通过；已核验暗黑中文、明亮英文及 390px 触控。服务重启被自动审批阻止，核对后端一致后保持原服务并发布已验收的静态产物，正式资源与验收构建一致，真实白板未变。完整证据见 `.megit/verification/git-help/`，发布以 `artifact-deploy.json` 和 `live-check.json` 为准。
