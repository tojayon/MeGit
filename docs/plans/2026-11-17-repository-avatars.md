# 仓库头像

- 每个仓库可选 `logoPath`，保存仓库内图片的相对路径；旧配置继续使用默认仓库图标。设置跟随仓库，在多个白板中共用，不修改 Git 文件或历史。
- 点击仓库详情标题图标进入选择窗口，按目录浏览、预览后保存；支持恢复默认。仅浏览已登记仓库，沿用同源与会话令牌，拒绝越界路径、Git 内部文件和越界链接；图片限制 1 MiB。
- 白板、导航、仓库索引、分组及关系端点共用头像组件。失败时回退默认图标，设置窗口显示具体原因。支持本机 SVG、PNG、JPEG、WebP、GIF 和 ICO，不把 SVG 注入页面。
- 复用共用弹窗、按钮和提示，采用双主题语义色；文案同步中英文，检查键盘、触控、目录切换、取消、持久化及旧白板兼容。
- 在独立数据目录与临时仓库验证，不重启或改写主会话正在使用的服务，不提交或推送。
