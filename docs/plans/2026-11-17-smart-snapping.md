# MeGit 智能吸附与提示浮层实现计划

**目标：** 修复 tooltip 被画布、导航和滚动容器遮挡的问题；加入默认开启、可关闭的元素智能吸附，避免排版产生几像素的误差。

**实现结构：** Tooltip 共用顶层浮层与视口避让，不改变既有关闭、焦点、触摸与 Escape 规则。拖动时根据实际测量尺寸，在纯几何模块计算边缘、中心和等间距；所选内容作为整体移动，拖动结束只保存一次。工具开关保存在浏览器偏好，参考线不进入工作区或导出。

**技术：** React 19、React Flow、原生 Popover top layer、TypeScript、Vitest 与 Edge Playwright；复用主题颜色和 i18next。

## 1. 复现提示遮挡并统一浮层

- `e2e/snapping.spec.ts` 复现左上工具栏提示在导航边界被裁切、窄屏视口边缘和原生模态中的提示；以边界与实际绘制命中测试验证完整可见。
- `src/components/Tooltip.tsx`、`IconButton.tsx` 统一浮层，不再按调用处选择 portal；保留 `InspectorDock` 自定义锚点类名。提示采用屏幕坐标、空间不足换向并限制在视口内，兼容模态与滚动容器。
- `src/styles.css` 移除依赖局部父元素的定位选择器，沿用现有颜色。`DesignSystemPage` 添加受限容器真实示例，双语文案同步。
- 先验证原实现失败，再实现并回归 `e2e/overlays.spec.ts` 的关闭和焦点规则。

## 2. 智能吸附几何

- 新增 `src/lib/snapping.ts` 与 `tests/snapping.test.ts`；先写失败用例覆盖六种对齐、不同大小、等间距、缩放阈值、离开范围释放、稳定候选、多选／分组排除自身、隐藏元素、边界和锁定。
- 默认只吸附附近可见元素。屏幕距离阈值 6px，保留中的候选允许 10px 释放范围，避免缩放改变手感与候选抖动。
- 单个节点按外框计算；分组按外框，多选按整体边界，保持成员相对位置。排除移动对象、受其影响的父组与隐藏对象。
- 同行／同列元素提供居中等间距和延续既有间距的吸附；参考线直接展示实际匹配关系。

## 3. 接入拖动、偏好和工具栏

- `src/preferences/storage.ts` 增加 `snappingEnabled`，旧配置默认开启；新增偏好回归。
- `CanvasTools.tsx` 增加磁铁按钮和 `aria-pressed`，中英文提示说明 Alt 临时跳过。
- `FlowCanvas.tsx` 在手势开始冻结坐标、测量尺寸与候选，拖动过程中只更新临时位置和参考线；结束使用最终吸附坐标并入一次撤销历史。关闭、Alt、锁定和键盘微调按各自规则处理。
- 多选、分组、聚焦、缩放／平移、撤销和刷新保持一致；参考线跟随视角，不拦截鼠标，也不参与导出。

## 4. 验收和发布

- Edge 使用独立端口和数据目录，覆盖精确落点、实时参考线、开关／刷新、Alt、不同缩放、多选、分组、撤销／重做、锁定和双主题双语。
- `npm run check`、相关及完整 `npm run test:e2e`，核对真实截图。同步 README、设计规范、主题约定及验证记录。
- 保留同目录其他会话改动；不提交或推送。正式更新前核实 MeGit 监听与进程身份，重新构建后只重启 MeGit，核对白板哈希与只读正式资源。
