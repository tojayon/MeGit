# 提交点操作

用户已授权以图上的提交点承接新建分支。点击真实提交圆点，先打开附近的顶层浮层，提供从此提交新建分支、查看差异、复制完整提交编号；移除地图工具栏中的新建入口。分支枝梢仍打开分支详情。

1. 用临时真实 Git 仓库验证从历史 SHA 创建、保留当前代码及草稿、拒绝非提交或不可达对象和过期确认；沿用严格会话和仓库校验。
2. 新建窗口冻结仓库快照及所选提交，锁定起点，默认仅创建，显式选择才切换。服务只允许明确的 COMMIT 模式及完整 SHA，校验对象类型和当前 HEAD／实际分支可达性，禁止任意 revision。
3. 浮层按屏幕坐标定位和避让，不随图形缩放，内部可滚动；支持触控、键盘、Escape、外点收起、安静焦点交接与浮层互斥。每个动作具有详细双语 tooltip；复制有成功及失败反馈。
4. 复用语义主题和尺寸 token，同步真实设计规范示例、旧用例及说明。用隔离数据完成 Edge、双主题双语、窄屏与并排详情验证。
5. 仅迁回本轮改动并保留主目录其他改动；集成检查、审查、正常构建后更新核实身份的 MeGit 预览。不开真实仓库写测试，不自动提交或推送。

后续可扩展两个提交间的比较和创建标签；本轮不添加历史重写操作。
