# 连线路线横竖吸附

沿用白板默认开启的磁铁开关，路线编辑不增加常驻入口。折点吸附到前后相邻点的水平或垂直位置，水平／垂直线段沿法向吸附到本条路线的其他固定点，保持端点与线段方向；斜线段继续自由平移。

阈值与节点拖动一致：6 屏幕像素进入、10 像素释放，候选稳定排序并保留当前轴锁定。Alt 按下与松开无需移动即可重算。方向键用于精细调整，保持自由步进。

纯函数集中计算坐标、锁定和参考线；共用 useEdgeRoute 订阅偏好并管理瞬态预览。参考线使用既有 accent，跟随世界坐标缩放，禁止命中，不保存、不导出。取消手势清除参考线和锁；释放仅写回一次。

验收覆盖两类线、两主题双语、0.5／1／2 单元几何与0.5／1.2真实视口缩放、Alt 即时切换、取消、开关、撤销和刷新。使用独立副本和临时数据，正式实例由主对话统一更新。
