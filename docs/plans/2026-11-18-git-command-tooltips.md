# Git 命令提示与提交事件

按用户要求直接实施：Git 功能按钮的详细提示追加当前上下文的 PowerShell 命令；需要输入或确认时明确说明阶段，在确认按钮上显示最终参数。复制及纯视图操作不伪造 Git 命令。保持参数数组执行和既有服务校验，共享参数构造避免预览与实际动作漂移；推送目标读取真实配置，不由显示名称猜测。

提交点提示只显示具体说明、作者、时间、父提交与引用，按父数量区分初始／普通／合并提交，不把当前引用误说成历史分支创建事件。分支标签同样使用对象信息；通用图例、HEAD、折叠和操作说明集中到地图右上角问号。

所有普通 tooltip 鼠标悬停等待 500ms；已有动画提示采用相同标准。键盘立即显示，触控点击固定、Escape、滚动收起和延迟取消继续有效。共用常量、语义颜色与尺寸，维护中英文、真实组件示例及规范。

先补缺失行为的 Edge 红测与命令构造测试，再实现。使用 `.worktrees/` 独立工作区和虚构仓库，完成 check、相关及完整 Edge，合回时保留其他改动。正常构建，仅更新已核实的 MeGit 预览，正式核对只读；不提交或推送。
