# 刷新恢复浏览状态实施计划

**目标：** 页面刷新后恢复已打开的 Git 详情及顺序、当前对象、面板与分支地图位置，保持浏览连续。

**架构：** 白板内容和已有外观偏好沿用当前保存协议；新增版本化 `megit.view-state`，放在当前标签页的 sessionStorage。按白板和仓库身份隔离浏览状态，校验损坏值、失效对象和尺寸边界。仅恢复浏览内容及草稿，不重放 Git 动作、确认窗口或临时提示。设计规范示例默认不接入真实会话状态。

**技术：** React、TypeScript、sessionStorage、现有组件与双语资源。

1. 先补 Edge 红测：两个详情、地图选中／展开／缩放／滚动、横向位置和关闭白板，刷新后恢复。
2. 增加可测试的版本化会话存储与 React 共用状态／滚动恢复接口，覆盖坏数据、存储失败和有效值。
3. 接入 App 的详情、选择及浏览入口；接入详情横向滚动、仓库工作区／历史及草稿、分支视角和地图。异步内容准备完成再恢复，避免初始自动居中及默认状态覆盖已保存值。
4. 接入白板浏览工具、导航列表滚动、Git 课堂课程／步骤及窗口位置；必要位置在窗口缩小时限幅。
5. 增加刷新不会发出 Git 动作、关闭后不再恢复、失效对象清理、两个标签页独立、双主题双语和窄屏用例。
6. 执行 npm run check 与相关 Edge；同步规范与验证证据；只整合本轮差量，保留并行修改。正常构建更新已核实的本机 MeGit 实例，正式验收只读，不自动提交或推送。
