# 工作流面板紧凑顶部栏

**目标：** 中间工作流面板增加与右侧详情等高的标题栏，显示工作流名称、信息和关闭入口。

**设计：** 复用 `PanelHeader`、`InfoPopover` 与双主题语义样式，单行桌面 29px，触屏保持 44px 点击目标，长名称换行。信息展示原始工作流名称、说明及仓库／关系／分组数量。关闭仅隐藏当前工作流视图，保留内容、视角和右侧详情；可从原位置或左侧工作流列表重新打开。关闭状态仅属于当前页面，不写工作区或浏览器偏好。

1. 先用独立虚构仓库的 Edge 场景验证标题等高、信息按需显示、关闭／重开及内容不写入；记录旧实现失败。
2. 增加 `WorkflowHeader`，接入中间面板与设计规范页，沿用共享布局与浮层焦点规则。同步中英文和导航位置断言。
3. 更新使用说明、架构和设计规范，运行 `npm run check` 与相关 Edge 场景，验收双主题、双语、长名称、390px 触控和键盘。
