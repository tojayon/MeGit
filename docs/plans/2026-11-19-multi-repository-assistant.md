# 多仓库 AI 助手实施计划

**目标：** 将 MeWiki 紧凑会话面板的视觉与引用交互迁移到 MeGit，使用已有 AI 服务管理选定的多个仓库，先审阅计划再执行。

**架构：** 独立可调宽助手浮窗与现有 Git 详情并存。聊天历史、草稿、选择及位置只保存浏览状态；模型输出通过共享结构化契约校验。服务端生成有期限、只执行一次的计划，执行前复核登记仓库和真实 Git 状态，逐仓库按顺序执行既有 Git 操作，失败停止本仓库后续步骤并保留其他仓库的结果。刷新不能重放动作。

**技术：** React、i18next、Express、Zod、既有参数数组 Git 执行器、Vitest、Playwright/Edge。使用 MeGit 主题与本机图形，不引入 MeWiki 的硬编码配色、笔记控制器或运行时依赖。

## 1. 服务契约与执行

- `shared/assistant.ts` 定义对话输入、只允许获取／暂存所有／提交／推送的计划及逐步骤结果；目标限于用户选择的有效仓库，模型不能传路径或任意命令。
- `server/assistant.ts` 投影仓库状态与本地分支、调用已有模型传输；暂存差异仅在用户显式勾选时附加，所有文件内容视为数据。
- 服务端计划保存固定仓库快照、具体操作参数、命令预览与执行状态；客户端只能提交计划ID。生成不写 Git；执行只允许一次且防并发；过期／变更拒绝。
- `server/git.ts` 在既有仓库队列内增加可选前置复核，确保手动操作和助手不能插队覆盖已审阅状态；沿用推送快进／跟踪／远端地址／代理校验，不支持强推或任意终端。
- 先写真实临时仓库与本地裸仓库测试：未确认不写、两仓库提交推送、越权模型输出、过期状态、重复执行、失败后跳过、无敏感附加。

## 2. 会话界面

- `src/components/AssistantPanel.tsx` 与共用展示组件实现 MeWiki 风格消息、顶部紧凑工具、底部仓库引用标签／输入／发送停止按钮，按需仓库选择、历史与设置入口。
- `src/lib/assistant-storage.ts` 保存有界、严格校验的历史与草稿，计划恢复时从服务查询实际状态，禁止恢复时自动执行；独立于白板内容。
- 侧栏增加「AI 助手」入口；软件设置继续承接服务配置与原流程图功能，独立助手不占 Git 详情列。浮窗拖动、键盘移动、调宽、窄屏限幅及刷新恢复。
- 计划按仓库显示分支、暂存范围、可编辑提交说明与目标跟踪分支；详细命令按需展开；统一确认一次，运行中可停止后续步骤，已完成不回滚、不重跑。
- `/design-system` 复用真实展示组件的虚构会话与执行状态，不发起 API 请求。全部文案中英同步，复用语义颜色。

## 3. 验收与交付

- Edge 覆盖多轮对话、仓库范围、计划审阅／提交推送、失败保留、取消、刷新恢复不重放、暗黑中文／明亮英文、390px与键盘提示。
- 同步 README、架构、界面与多语言规范和验证记录；运行 `npm run check` 与相关 `npm run test:e2e`，证据写 `.megit/verification/assistant/`。
- 保留当前工作树，不自动提交推送、不改真实仓库或配置。正式重启如仍受此前审批限制，先完成可审阅成果并单独处理。
