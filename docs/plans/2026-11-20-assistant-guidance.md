# AI 回复快捷引导

目标：按仓库在回复下提供现有功能入口，修复前置条件后由用户继续对话。

已确认：复用远端添加／跟踪／发布表单、工作区、分支地图、远端访问检查和设置；提交推送仍须审阅。结构化引导只含登记仓库 ID 和有限动作类型，不解析回复文字或执行模型命令。

实施顺序：
1. 共享契约及实际状态可用性；测试无远端、无跟踪、冲突、越界和去重。
2. 助手回复返回并保存引导；兼容旧模型输出，服务端过滤无效入口。
3. 复用按钮／表单，点击重新核对状态；状态改变后收起失效入口，提供继续草稿。
4. 接入错误恢复、双语和语义主题；规范页提供同一按钮和表单的纯本地示例。
5. 独立虚构仓库、独立端口验证真实添加／发布、失败恢复、刷新、键盘和窄屏。执行 npm run check 及相关 Edge 场景，记录证据。

本侧聊只修改本功能，不重启正式服务，不提交或推送用户仓库，不与主对话并行改造浮窗。
