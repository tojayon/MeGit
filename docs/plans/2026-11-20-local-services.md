# 本地服务实施计划

**目标：** 在仓库详情启动、停止和重启一个前台开发服务，查看状态、冲突和最近输出。

**架构：** 按规范化的工作树路径保存本机授权，不写入白板。启动前复核目录、分支和入口。Windows 监督进程创建进程时直接加入独立 Job Object；只将该组内的 TCP 监听视为就绪，不按端口终止进程。

**技术：** 现有 Express、React/i18next、Windows PowerShell 和 Win32 Job Object/TCP API，不新增运行时依赖。

1. 用临时虚构仓库验证授权、路径、端口冲突及进程组清理；先运行失败测试。
2. 实现独立配置、受控启动、有界日志及双语错误。
3. 加入仓库详情入口，复用表单、提示和对话框，以 Edge 验证双主题、双语和真实服务流程。
4. 更新使用说明和验证记录；保留用户白板与未提交变更，不提交、不推送。
