# AI 项目交付实施计划

**目标：** 在既有聊天面板中指定单个仓库，授权模型按需查看目录及读取文件，审阅后新建或修改文本文件，可同时保存生成的 PowerShell 启动入口配置。

1. 先用临时仓库和虚构 AI 服务覆盖目录筛选、生成前不写入、审阅后写入、过期内容拒绝及本地服务仅保存，再实现有界项目工具和仅存内存的计划。
2. 复用 AI 服务配置、Host／同源／令牌校验及本地服务保存。默认关闭；投影目录只包含允许的相对路径；文件读取按需、有界；用户授权绑定服务地址、模型和仓库。确认只接受计划标识与服务信任选项，不接受替换文件内容。
3. 在 AI 设置添加开关，现有聊天面板中加入任务入口和紧凑审阅卡。显示发送目标、发送过内容的文件、变更前后文本、目标启动设置及实际写入结果。取消不落盘，过期不重放，不自动执行脚本或 Git 操作。
4. 更新中英文说明、设计规范和验收记录。使用临时工作树与模拟服务验证安全边界及 Edge 完整交互，不启动真实项目。
