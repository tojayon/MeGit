# Windows 窗口设置

- 在软件设置增加桌面版「界面」分类。系统标题栏默认显示，关闭到托盘默认禁用；设计规范示例不触发系统操作。
- 通过仅限 `main` 和桌面回环来源的 Tauri 命令读取和更新原生偏好。不把桌面权限扩展给浏览器版、本机 HTTP API 或外链。窗口偏好独立于白板及浏览器偏好持久化。
- 隐藏系统标题栏时提供应用内拖动区域及最小化、最大化／还原和关闭按钮。启用关闭到托盘后，托盘和再次启动都能恢复窗口；托盘的退出菜单仍走现有退出清理流程。
- 先用 Edge 回归桌面设置交互、双语、失败提示和浏览器隔离，再验证 Rust 协议和持久化、打包后端与 Windows 安装包。安装、拖动、托盘与退出需分别记录实机验收状态。
