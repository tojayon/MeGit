# MeGit Windows 桌面版实施计划

**目标：** 同一仓库发布独立的 Tauri + WebView2 安装包，浏览器版无须桌面工具链。

**设计：** `desktop/` 管理打包、窗口、单实例和后端生命周期。安装包内置锁定版本的 Node、Web 产物和后端生产依赖。WebView2 与 API 使用同一固定回环来源；遇到端口冲突不加载其他程序。桌面数据与开发版数据分离。

1. 先用测试覆盖内置 Node 与仓库 Node 的分离、回环边界及父进程断开。
2. 实现生产后端就绪及退出协议，保留原有 Git、路径、令牌和同源检查。
3. 加入 Windows 外壳、单实例和按用户安装；验证 Node 校验、WebView2 和打包产物。
4. 在隔离环境运行网页版和安装包验收，并补充中英文安装、升级和数据迁移步骤。
