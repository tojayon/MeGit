# 本地仓库连线：审阅并合并

保留现有快进操作，给两份登记工作树之间的代码整合连线增加独立的合并开关。只处理明确选中的本地分支，不引入验收记录、项目专用脚本、联网同步或自动提交。

1. 测试以临时克隆构造分叉、冲突与结果过期；先验证现有 API 不支持合并。
2. 读取两端固定提交，通过临时对象查找路径计算共同历史、各自提交及来源改动；预览不写入仓库。准备前重新校验连线授权、分支、两端提交和目标干净状态，仅从本机导入对象，再执行不提交的三方合并。
3. 保存合并归属与两端版本，结合 Git 的合并状态恢复审阅。提交前重新核对已审阅的暂存结果；冲突和未暂存修改必须先处理。取消必须显式确认，不接管外部发起的合并。
4. 连线入口接入双语模态、冲突列表、差异与确认。使用独立 Edge 场景覆盖预览、刷新恢复、冲突、取消和提交；最后同步使用说明并核对预览服务。
