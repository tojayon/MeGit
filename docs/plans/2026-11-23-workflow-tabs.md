# 工作流标签与桌面窗口控件

- 从导航打开已有工作流或创建工作流时加入有序标签列表；重复打开只激活。切换不写入白板；浏览记录沿用当前页面的会话存储。关闭当前标签切到右侧相邻标签，若没有则选左侧；关闭最后一个保留空态和恢复入口。
- 标签内从左到右排列工作流信息、名称与关闭；通过方向键切换，Home／End 跳转，Delete 关闭。标签栏横向溢出时滚动，右侧控件不参与滚动。
- Windows 隐藏系统标题栏后复用工作流标签栏，空白处可拖动，最小化、最大化／还原和关闭固定在栏的右侧。没有打开标签时控件依然可见，窄屏详情覆盖层从标签栏下方开始。
- 验收标签切换／关闭／刷新、白板不写入、右侧详情和窄窗口，以及双主题、两种语言与桌面桥接分离。构建独立试装包，不替换旧版或重启正在运行的实例。
