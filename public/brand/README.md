# MeGit 标志

- `megit-logo.svg`：图形与 MeGit 名称等高组合，透明画布为 960 × 280。
- `megit-icon.svg`：不含文字的独立图形，方形画布为 512 × 512。
- `preview.png`：完整标志、独立图形、深色背景及小尺寸效果预览。
- `color-palette.html`：可切换主题、复制色值的配色色卡。
- `megit-palette.svg`：可编辑的矢量色卡。
- `megit-palette.png`：便于预览和分享的色卡图片。
- `palette.json`：品牌原色、色阶、中性色、功能扩展及双主题语义映射。

配色用途和维护流程见 [品牌配色规范](../../docs/COLOR_GUIDELINES.md)。运行 `npm run brand:palette` 可从颜色数据重建色卡。

两份 SVG 均为透明背景、纯矢量，名称已转为路径，不依赖字体或外部图片。白色 Git 节点与连线是标志的一部分。

按少锚点、平滑曲线原则重绘：四块主轮廓分别使用 8、12、16、9 个锚点，共 45 个；节点使用圆与椭圆，连线使用单条描边。完整标志中的字形也使用精简的直线与贝塞尔曲线。

完整标志以名称的可见高度为基准，图形等比缩放至 0.464 倍，两者可见高度均约 223 个画布单位，上下边缘对齐，间隔约 36 个单位。调整仅使用分组变换，不增加锚点、不拉伸字形；独立图形的比例与画布不变。

网页中可直接使用 `/brand/megit-logo.svg` 与 `/brand/megit-icon.svg`。保持原始宽高比缩放即可；独立图形已留出方形画布内的必要空白。

应用内统一使用 `src/components/BrandLogo.tsx` 复用独立图形与文字分组，不复制路径。独立图形作为 SVG 图片加载，避免浏览器切换主题时丢失跨文件引用的渐变。完整 SVG 的名称通过 `currentColor` 绘制，直接作为图片打开时仍为原始深蓝色；应用内则由 `--brand-wordmark` 跟随主题。左侧导航完整 Logo 宽 84px；折叠 Ribbon 中图形画布按 `84 × 0.464 × 512 ÷ 960` 计算，约 20.79px，使展开／折叠的实际图形保持同一尺寸。两者均使用透明容器，直接呈现所在栏位的背景；浏览器图标直接使用独立图形。展开导航及窄屏抽屉在 Logo 右下方显示产品版本徽标。

暗黑主题的应用 Logo 仅在图形上叠加柔白细轮廓，导航实际尺寸下约 0.5px，由 `--brand-symbol-outline` 控制；明亮主题轮廓透明。轮廓从现有图形的透明度边界生成，不增加路径锚点，也不改变原始 SVG、渐变与字标。原始资源和 `preview.png` 仍展示标准品牌标志；此轮廓属于暗黑界面的显示辅助。展开导航顶部行高 44px，帮助图标在 Logo 右侧靠右对齐，折叠 Ribbon 的帮助入口位于底部。
